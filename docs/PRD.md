# 🔗 마이링크 (MyLink) 제품 요구사항 정의서 (PRD)

## 1. 프로젝트 개요
### 1.1. 프로젝트명
**마이링크 (MyLink)**

### 1.2. 목적
사용자의 다양한 소셜 미디어, 포트폴리오, 블로그 등 흩어져 있는 온라인 접점을 **하나의 직관적인 URL(Single Point of Entry)**로 통합하여 제공합니다. 군더더기 없는 미니멀한 기능과 강렬한 비주얼을 통해 퍼스널 브랜딩을 지원합니다.

### 1.3. 대상 사용자
*   **크리에이터 / 인플루언서:** 인스타그램, 유튜브, 틱톡 등 팔로워에게 모든 채널을 한 번에 안내하고 싶은 사용자.
*   **프리랜서 / 비즈니스 오너:** 서비스 소개 및 결과물 링크를 심플하게 공유하고 싶은 전문가.
*   **일반 사용자:** 자신의 프로필을 세련된 페이지로 요약하여 공유하고 싶은 누구나.

---

## 2. 필수 기능 목록 (MVP)

1. **사용자 인증:** Firebase 기반 구글 소셜 로그인 (온보딩 간소화)
2. **프로필 관리:** 닉네임 기반 URL 슬러그 자동 생성 및 실명/바이오 인라인 편집 기능
3. **링크 관리:** URL 추가/편집/삭제 (활성화 여부 및 순서 변경 기능 제외)
4. **링크 아이콘 자동화:** Google Favicon API를 통해 등록한 URL의 파비콘을 자동으로 아이콘으로 설정
5. **반응형 프로필 페이지:** 모바일 및 데스크탑에 최적화된 공개 프로필 페이지

*(참고: 향후 추가 기능으로 각 링크의 클릭 조회수 통계 확인 기능이 검토될 예정입니다.)*

## 3. 기능 상세 설명

### 3.1. 사용자 인증 및 계정 관리
*   **로그인 방식:** **Firebase Auth (Google Social Login)** 전용.
*   **URL 슬러그 정책:** 가입 시 구글 이메일의 ID 부분을 초기 `displayName`(URL 슬러그)으로 할당합니다. (예: `mylink.site/nsy`)
*   **데이터 스토리지:** 사용자의 핵심 정보(닉네임, 이름, 소개글)는 Firestore의 유저 문서에 저장됩니다.

### 3.2. 관리자 대시보드 (Admin Interface)
*   **인라인 텍스트 편집 (Inline Editing):** 
    *   사용자의 `username`(페이지 노출 이름), `bio`(소개글)를 텍스트를 클릭하여 즉시 수정 가능합니다. 이름은 상시 수정 가능합니다.
*   **이름 기반 아바타 (Initial Avatar):**
    *   사용자의 `username` 첫 글자를 딴 자동 생성 아바타를 노출합니다.
*   **링크 리스트 관리:**
    *   **링크 추가/삭제:** 제목과 URL을 입력하여 링크를 추가하거나 삭제할 수 있습니다.
    *   **아이콘 자동 설정:** 사용자가 URL을 입력하면 **Google Favicon API**를 호출하여 해당 사이트의 파비콘을 목록 아이콘으로 자동 표시합니다.
    *   **제외 사항:** 링크 활성화/비활성화 전환 기능 및 드래그 앤 드롭을 통한 정렬 기능은 포함하지 않습니다.

### 3.3. 공개 프로필 페이지 (Public Profile)
*   **프로필 헤더:** 상단 중앙에 이름 첫 글자 아바타, 그 아래에 사용자가 설정한 `username`과 `bio` 배치.
*   **네오브루탈리즘 스타일:** 강렬한 색상 대비, 두꺼운 블랙 보더, 하드 섀도우 디자인 적용.
*   **공유 기능:** 현재 페이지 주소를 클립보드에 복사하는 버튼 제공.

## 4. 기술 스택 및 데이터 모델

| 구분 | 기술 Stack | 비고 |
| :--- | :--- | :--- |
| **Frontend** | React / Next.js (App Router) | |
| **Styling** | Vanilla CSS / Tailwind CSS | |
| **Backend** | Firebase (Firestore, Auth) | |
| **API** | Google Favicon API | 아이콘 자동 생성용 |

### 데이터 모델 구조 (Firestore)
1. **Users (Collection)**
    *   `uid`: 고유 키 (Document ID)
    *   `displayName`: URL 슬러그로 사용될 고유 닉네임
    *   `username`: 프로필 노출 이름 (수정 가능)
    *   `bio`: 소개글
2. **Links (Sub-collection of a User)**
    *   사용자 문서 하위에 `links`라는 이름의 서브 컬렉션으로 구성
    *   각 링크 문서 필드: `id`, `title`, `url`, `createdAt`
