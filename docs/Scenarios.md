# 👨‍💻 마이링크 (MyLink) 사용자 시나리오

본 문서는 정제된 필수 기능을 중심으로 사용자가 겪게 될 주요 여정을 시나리오 형태로 기술합니다.

---

## 1. 신규 사용자의 첫 온보딩 (가입 및 프로필 생성)
1.  **접속:** 마이링크 메인 페이지에 접속합니다.
2.  **로그인:** '구글로 시작하기' 버튼을 통해 본인의 지메일 계정으로 인증합니다.
3.  **자동 생성:** 로그인 완료 시 이메일 ID를 기반으로 `displayName`(URL 슬러그)이 자동 할당됩니다.
4.  **대시보드 진입:** 관리자 대시보드로 이동하며, 이름의 첫 글자가 담긴 아바타와 자동 설정된 이름(`username`)을 확인합니다.

---

## 2. 링크 추가 및 관리 (콘텐츠 구성)
1.  **링크 추가:** 대시보드에서 제목과 URL을 입력하여 새 링크를 생성합니다.
2.  **아이콘 확인:** 입력한 URL의 파비콘이 자동으로 아이콘으로 설정되는 것을 확인합니다.
3.  **인라인 편집:** 링크 목록에서 제목을 직접 클릭해 원하는 문구로 실시간 수정합니다.
4.  **링크 삭제:** 더 이상 필요 없는 링크는 목록에서 삭제합니다. (순서 변경이나 활성 상태 전환 없이 단순 관리)

---

## 3. 프로필 커스터마이징 (개인화 작업)
1.  **이름 수정:** 상단의 이름을 클릭하여 본인이 노출하고 싶은 이름으로 변경합니다.
2.  **아바타 연동:** 이름 수정 시 아바타의 첫 글자도 함께 변경되는 것을 확인합니다.
3.  **소개글 작성:** 이름 아래의 소개란을 클릭하여 짧은 소개 문구를 입력합니다.

---

## 4. 링크 공유 및 방문자 경험 (최종 소비)
1.  **링크 클릭:** 인스타그램이나 X(트위터) 프로필에 등록된 마이링크 주소를 클릭합니다.
2.  **페이지 감상:** 모바일과 데스크탑 어디서나 최적화된 네오브루탈리즘 스타일의 프로필 페이지를 확인합니다.
3.  **이동 및 상호작용:** 목록화된 링크 버튼을 클릭하여 해당 사이트로 이동합니다.
4.  **주소 복사:** 프로필 상단의 '주소 복사' 버튼을 사용하여 자신의 프로필을 다른 곳에도 쉽게 공유합니다.
