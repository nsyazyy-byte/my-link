# 👨‍💻 마이링크 (MyLink) 사용자 시나리오

본 문서는 서비스의 핵심 기능을 중심으로 사용자가 겪게 될 주요 여정을 시나리오 형태로 기술합니다.

---

## 1. 신규 사용자의 첫 온보딩 (가입 및 프로필 생성)
**사용자:** 프리랜서 디자이너 '나디자인' 씨

1.  **접속:** SNS 광고를 보고 마이링크 메인 페이지에 접속합니다.
2.  **로그인:** '구글로 시작하기' 버튼을 누르고 본인의 지메일 계정(`nadesign@gmail.com`)으로 인증합니다.
3.  **자동 생성:** 로그인이 완료되자마자 시스템은 이메일 ID를 기반으로 `nadesign`이라는 닉네임(URL 슬러그)을 자동 할당합니다.
4.  **대시보드 진입:** 즉시 관리자 대시보드로 이동하며, 화면 상단에는 'N'자가 적힌 깔끔한 아바타와 함께 `nadesign`이라는 이름이 표시됩니다.
5.  **확인:** 본인의 고유 주소인 `mylink.site/nadesign`이 생성되었음을 확인합니다.

---

## 2. 링크 추가 및 관리 (콘텐츠 구성)
**사용자:** 인스타그램 인플루언서 '지니' 님

1.  **링크 추가:** 대시보드에서 '새 링크 추가' 버튼을 클릭합니다.
2.  **입력:** 제목에 '지니의 일상 유튜브', URL에 유튜브 채널 주소를 입력합니다.
3.  **자동 아이콘:** 주소를 입력하자마자 유튜브 로고 파비콘이 링크 옆에 자동으로 표시되는 것을 보고 만족합니다.
4.  **인라인 편집:** 추가한 링크의 제목이 너무 긴 것 같아, 목록에서 제목 텍스트를 직접 클릭해 '지니 유튜브'로 짧게 수정합니다. 별도의 저장 과정 없이 즉시 반영됩니다.
5.  **링크 삭제:** 예전에 운영하던 블로그 링크 옆의 휴지통 아이콘을 눌러 목록에서 지웁니다.

---

## 3. 프로필 커스터마이징 (개인화 작업)
**사용자:** 대학생 '이공대' 군

1.  **이름 수정:** 대시보드 상단의 이름을 클릭하여 '이공대'에서 '코딩하는 공대생'으로 변경합니다.
2.  **아바타 변화:** 이름이 변경됨에 따라 아바타의 글자가 '이'에서 '코'로 바뀌는 것을 실시간으로 확인합니다.
3.  **소개글 작성:** 이름 아래의 한 줄 소개란을 클릭해 "함께 성장하는 개발자, 공대생입니다."라고 입력합니다.
4.  **실시간 프리뷰:** 대시보드 옆의 미리보기 화면에서 실제 공개될 페이지의 모습이 네오브루탈리즘 스타일로 힙하게 변하는 과정을 감상합니다.

---

## 4. 링크 공유 및 방문자 경험 (최종 소비)
**사용자:** 나디자인 씨의 인스타그램 팔로워 'A' 씨

1.  **링크 클릭:** 나디자인 씨의 인스타그램 프로필에 있는 `mylink.site/nadesign` 주소를 클릭합니다.
2.  **첫인상:** 모바일 브라우저에서 강렬한 테두리와 하드 섀도우가 적용된 독특한 네오브루탈리즘 디자인의 프로필 페이지가 열립니다. 상단에는 '나'라는 아바타가 반겨줍니다.
3.  **상호작용:** 버튼 위에 손가락을 올리자(Hover/Touch) 버튼이 툭 튀어나오는 듯한 애니메이션이 실행됩니다.
4.  **이동:** '포트폴리오 보러가기' 버튼을 클릭하여 나디자인 씨의 개인 웹사이트로 원활하게 이동합니다.

---

## 5. 기존 사용자의 재방문 및 유지보수
**사용자:** 마케터 '김마켓' 씨

1.  **재진입:** 메인 페이지에서 다시 로그인을 수행합니다. 별도의 비밀번호 입력 없이 구글 계정으로 즉시 대시보드에 진입합니다.
2.  **업데이트:** 진행 중인 이벤트가 종료되어 관련 링크를 삭제하고, 새로운 예약 폼 링크를 상단에 추가합니다.
3.  **주소 복사:** 변경된 페이지를 홍보하기 위해 상단의 '주소 복사' 버튼을 눌러 본인의 카카오톡 프로필 주소로 업데이트합니다.
